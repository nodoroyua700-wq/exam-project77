# Exam Project Portal

Skillwill-ის პრაქტიკული სასწავლო პროექტი Git-ისა და GitHub-ის ვერსიის კონტროლის სავარჯიშოდ.

## პროექტის ფაილები

- `index.html` — ვებგვერდის სტრუქტურა და შინაარსი.
- `index.css` — დიზაინი, ნავიგაცია და მობილურზე ადაპტირებული განლაგება.

## გაშვება

გახსენით `index.html` ბრაუზერში ან გახსენით პროექტის საქაღალდე Visual Studio Code-ში.

## Git-ის პრაქტიკა

პროექტი განკუთვნილია Git-ის საწყისი კომიტის, განშტოებების, merge-ისა და კონფლიქტის მოგვარების სავარჯიშოდ. GitHub-ზე საჯარო რეპოზიტორის შექმნა, განშტოებების ატვირთვა და commit-ების ისტორიის წარდგენა ცალკე უნდა შესრულდეს და შემოწმდეს.
